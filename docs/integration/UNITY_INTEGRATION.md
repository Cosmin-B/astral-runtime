# Unity integration

The maintained Unity package guide is
[`plugins/unity/README.md`](../../plugins/unity/README.md). It covers package
layout, native library placement, runtime ownership, streaming, jobs, samples,
and editor tests against the bindings that ship in this repository.

For the allocator bridge, see
[`plugins/unity/ALLOCATOR_INTEGRATION.md`](../../plugins/unity/ALLOCATOR_INTEGRATION.md).

The package includes six focused samples:

- [Streaming chat](../../plugins/unity/Samples~/StreamingChat/README.md)
- [Multiple conversations](../../plugins/unity/Samples~/MultipleConversations/README.md)
- [Stateful NPC](../../plugins/unity/Samples~/StatefulNpc/README.md)
- [Local knowledge](../../plugins/unity/Samples~/LocalKnowledge/README.md)
- [Character variants](../../plugins/unity/Samples~/CharacterVariants/README.md)
- [Multimodal input](../../plugins/unity/Samples~/MultimodalInput/README.md)

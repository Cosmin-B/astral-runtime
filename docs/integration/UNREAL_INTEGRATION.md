# Unreal Engine integration

The maintained Unreal plugin guide is
[`plugins/unreal/AstralRT/README.md`](../../plugins/unreal/AstralRT/README.md).
It describes the module, UObject ownership, byte-stream delivery, Blueprint
surface, third-party library layout, sample project, and automation commands
against the plugin that ships in this repository.

Use the [UE 5.7 quickstart](UNREAL_57_QUICKSTART.md) for the pinned container
and packaged-sample workflow.

The sample project includes these components:

- `UAstralStreamingChatComponent`
- `UAstralMultipleConversationsComponent`
- `UAstralStatefulNpcComponent`
- `UAstralLocalKnowledgeComponent`
- `UAstralCharacterVariantsComponent`
- `UAstralMultimodalInputComponent`

Their source and setup instructions are under
[`examples/unreal/AstralSample`](../../examples/unreal/AstralSample/README.md).
